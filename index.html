A small language model
that is not a transformer.

PSSA reads text one token at a time through a recurrent state-space layer, keeps a bank of episodic memories it can look things up in, and rewrites part of its own weights while it runs. Written in Rust from scratch: no PyTorch, no TensorFlow, no ML framework underneath.

How it differs from a transformer

A transformer scores every pair of tokens in the context, so its cost per step grows with the square of sequence length and the whole context is re-read at every step. PSSA carries one fixed-size state along the sequence in a single left-to-right pass, and looks things up in a memory bank instead of re-reading the context, so cost grows linearly with length.

One pass per token: state carries forward, the memory bank is read and written every step, and a learned gate decides how much retrieved memory blends into the token stream.
  • Linear cost, not quadratic. No attention map: the cost of a step does not grow with context length.
  • Episodic memory. Fixed-capacity (key, value) slots written during the forward pass: round-robin overwrite, exact full-scan soft read. Not an ANN index.
  • Plasticity. Part of the weights updates every token while the model runs, so the model changes as it reads.
  • Checkable gradients. A scalar reference path every batched kernel is differentiated against, verified to about 3e-8.
